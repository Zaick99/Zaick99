## Projects

### [DuckNote](https://github.com/Zaick99/DuckNote)

Technical notes and a network scanner in the same window. Write an address in a
note and DuckNote checks it on its own; scan a subnet and the results come back
into the text. Code blocks are coloured by the language they speak, guessed from
the code itself. Notes can be encrypted.

## How I work

Every release ships as a single file, because an application that needs an
installer is an application nobody tries. Interfaces are built for the keyboard
first. Code is written to be read: one file, one responsibility; the happy path
is the body and errors leave early.
